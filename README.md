# 🛒 Retail Price Optimization using Machine Learning

## 📌 Overview

This project uses Machine Learning to predict the optimal selling price of retail products based on factors such as product cost, demand, discounts, competitor prices, and inventory levels. The goal is to help retailers maximize profit while maintaining competitive pricing.

## 🎯 Objectives

- Analyze retail sales data
- Predict optimal product prices
- Improve pricing decisions
- Maximize revenue and profit

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- Streamlit

## 📂 Project Structure

```
Retail-Price-Optimization/
│── Documnet/
│── app.py
│── requirements.txt
│── README.md
```

## 🚀 How to Run

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit app:

```bash
streamlit run app.py
```

## 📊 Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Price prediction
- Interactive Streamlit dashboard

## 📈 Outcome

The model predicts an optimal selling price based on product and market-related features, helping retailers make data-driven pricing decisions.
